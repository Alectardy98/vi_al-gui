# EC42 · Electrocapacitive / Topre

Calibration, per-key actuation, Rapid Trigger and live sensors.

Install this ZIP from **Add-ons → Install from ZIP…**, then restart Vi_al.
Requires matching supported keyboard firmware. It does not flash firmware.

Package API: 1. Source entrypoint: `python/vi_al_addons/ec_42/provider.py`.
See the host project’s `docs/ADDONS.md` for the common format and hooks.
